# scripts/coldness · 冷门度系数的拟合与重验

这里放的是 `worker/src/coldness.js` 里那几个常量的**来历和复现方法**。
Worker 里只有结果（1.174 / 1.074 / 0.918 / 1.241 / 0.812 / 8.27），没有它们是怎么来的——
没有这两个脚本，那些数字就等于「一组没人能重跑的神秘常量」。

先说清楚它测的是什么：**别的玩家有多爱买同一组号**（一等奖注数 ÷ 每亿元销量）。
它只影响「万一中了要和多少人分奖」，**不改变中奖概率**，期望回报仍是负的。

```bash
node scripts/coldness/ssq-fit.mjs    # 双色球：重拟合 + 样本外验证 + 安慰剂 + 与线上常量对账
node scripts/coldness/dlt-fit.mjs    # 大乐透：负结果的可复现留档（当前无可发布系数）
```

两者都读 `scripts/randomness/data/*.json` / `*_asc.txt`（先跑 `fetch-ssq.mjs` / `fetch-multi.mjs`），
零 npm 依赖，`ssq-fit` 的统计内核直接复用 `scripts/randomness/lib.mjs`。

| 脚本 | 产出 | 进 CI | 结论 |
|---|---|---|---|
| `ssq-fit.mjs` | `docs/coldness-latest.md` + `out/ssq.json` | 是（`randomness.yml` 月度） | 5 个特征样本外同号、五分位最热/最冷 **1.506**（MW p=6.2e-10）、安慰剂 1.006/0.993 → **已发布** |
| `dlt-fit.mjs` | `out/dlt.json`（stdout 为原始报告） | 否，见下 | 目标样本外复现（1.30×），但固定奖级安慰剂全灭 → `keep=[]`，**不发布** |

## 共同的三条纪律

1. **特征定义必须与 `worker/src/coldness.js` 的 `present{}` 逐字一致。** 拟合的和上线的不是同一个东西时，
   验证就只是在自我确认。`ssq-fit` 会直接把线上源码里的 `m:` 值和冷热名单抓回来对账。
2. **冷热名单只能在训练段里挑。** 用全样本挑「哪些蓝球算热」再看效果 = 拿答案挑题目。
3. **每条效应必须配一个安慰剂。** 双色球的干净对照是**二等奖（只看 6 个红球，不含蓝）**：
   蓝球冷热在它上面必须 ≈1.00。测出显著不是发现，是实现有混淆（多半忘了按销量归一）。

## ssq-fit 的闸门（`COLDNESS: FAIL` + 退出码 1 的条件）

- 五分位最热/最冷 ≤ 1.2 —— 拥挤度弱到不值得作为一个功能存在
- 任一**已上线**特征样本外反号 —— 双色球的连号特征就是这样被踢掉的（0.992 → 1.028）
- 蓝球冷热打在二等奖上 |乘子 − 1| > 0.05 —— 安慰剂破了，整套结论作废
- 冷热名单 / 绝对刻度常量与 `coldness.js` 不符 —— 代码和数据说的是两套话

系数漂移（重拟合值与线上常量差 >0.02）只报 **⚠ 警告**、不判失败：每月数据变长，
小数点后第二位的漂移是常态，把它做成红灯只会让人无视这个闸门。改不改常量是人决定的事，
脚本负责把话说到脸上。

## 绝对刻度有个坑（已经踩过一次）

`avgFirstWinners = 8.27` 是**全体有销量的期**的均值（含一等奖空出的 4.7%），
而拟合样本按 `n1>0` 过滤后条件均值是 **8.68**。彩民每期都买，期望同奖人数必须把 0 算进去；
拿 8.68 当刻度会把 `estWinners` 系统性高估。脚本里两个数分开算、分开印，对账只比 8.27 那一个。

## 为什么 dlt 不进月度 CI

它的结论不会随每月新数据翻盘——缺的是**集合外的人气代理**（各组合实际投注分布），不是时间。
把「尚未解决」挂成每月一根红灯，只会训练人忽略红灯。叙述与全部中间量见
`docs/coldness-dlt-2026-09.md`；`out/dlt.json` 的 `verdict` 是机器可读版。

顺带记着为什么大乐透的安慰器天生偏严：**它没有任何一档奖金只依赖后区**（三等奖=前区5中+后区0中），
前区组合被超买时它的邻域（4中5）同样被超买，低奖级注数被同一机制推高。
双色球能用二等奖当对照，是因为二等奖恰好不看蓝球。

## 哪些彩种永远不会有 coldness

固定奖玩法中了就是固定金额，没人和你分：快乐8、福彩3D、排列3、排列5 全部不适用，
这是「不该做」，不是「还没做」。七乐彩 / 七星彩的一二等奖是浮动奖，理论上适用，
但要它们自己的经校验奖级列 + 安慰剂设计之后才能谈拟合——目前一列都没验过。

随机游戏，统计仅供娱乐，不保证中奖。
