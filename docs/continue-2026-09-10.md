## 双色球 3501 期实证结论（数据源已交叉校验）

- 数据：`data.17500.cn/ssq_asc.txt` 3501 期（2003001→2026104，31 列），与官方 cwl API 逐字段一致：2013 年 62 期全对、最近 100 期与用户 D1 全对、内部一致性 0 违规。清洗产物 `workspace/ssq.json`。
- 官方 `findDrawNotice` 忽略 `beginDate/endDate`，历史硬截 2062 期，但一次返回 `sales/poolmoney/prizegrades`（7 奖级中奖注数+单注奖金）。`datachart.500.com` 直连返 567 反爬。
- 独立性全 null：与上期重合 1.0831 vs 期望 1.0913（p=0.58）、lag-1 自相关 -0.0003（p=0.53）、平均遗漏 5.4923 vs 5.4929、最大遗漏 48 **低于**随机均值 52.7、蓝球连开 p=0.11、开奖位置 p=0.54。
- 均匀性：`chi2R=44.54`，但**零分布均值是 26.91 不是 32**（每期 6 号互斥 → E[χ²]=33(1-6/33)=27；用解析 df=32 会错判 p=0.069）。MC 双侧 p=0.021；逐号最大 |z|=2.25 而 33 号下期望最大 |z|≈2.13（p=0.74）。异常局域在 2015-2018（33 冷 z=-2.89）、周四和值 z=-2.97，2019 后消失 → 非平稳。族内 max|z| 联合校正 **p=0.019**（提示性，非发现）。
- 投注侧强显著（可操作）：一等 1.274×、二等（纯红）1.303×、p<1e-9；**安慰剂**六等（纯蓝）1.006× p=0.32。蓝球：一等蓝≤12 1.237× p<1e-9，**安慰剂**二等 1.007× p=0.69；六等按蓝球最热 09(374万) vs 最冷 01(211万)=1.768×，无单调性（01 最冷）。尾8 1.117×、尾4 0.903×。全红≤31 期一等平均 9.20 注 vs 含32/33 期 7.55 注 → 条件到手 +21.8%。

## 架构决策与理由

- **P0-5 选"改文案止血"而非"接通权重"**：接通会改变用户实际下注号码，而权重无统计依据；可见行为变更需另行论证。
- **新增 `money` 表而非 ALTER `draws`**：不动既有取数/入库路径，冷热度独立 JOIN 读取，回滚只需 DROP 一张表。
- **`coldness.js` 只做纯函数**：可离线用 `ssq.json` 全量验证，且不引入 Workers 禁用的 node 内置模块（手册 §7.1）。
- **reviewJob 改为 CI 显式 HTTP 调用**（保留 waitUntil 作 best-effort）：定时任务不依赖用户电脑开机（§7.4）。

## 环境坑（本 session 实测）

- Windows 原生 curl 不认 `/c/...` 与 `/tmp`，输出用 `C:/Users/...`；访问 workers.dev 加 `--noproxy '*' --ssl-no-revoke`。
- 同一文件多个 Edit 并行会 last-writer-wins → 必须串行 + grep 复验落盘。
- 节点路径含大小写：`D:/WorkBuddy/Data/.workbuddy/binaries/node/versions/22.22.2-2/node.exe`。
- **测试代码里不要整串写 `Authorization: "Bearer x"`**：会被环境的密钥脱敏改写（实测变成 `"***"`），结果全部请求 401、4 项测试假红。拆片段拼接时也要注意拼出的必须是完整的 `Bearer`——我曾拼成 `Bear t` 又是一轮假红。
- **D1 测试桩必须模拟 `WHERE kind=?`**（尊重 `bind` 的 kind）。否则 `reviewJob` 循环到 kl8 时会拿 fc3d 的待对账行按 `nums` 解析，用全 0 结果覆盖上一次 UPDATE，造成假阴性——我一度因此误判产品代码有 bug。真实产品代码没问题，是桩的问题。
- grep 校验产物时注意：`(cd worker && ...)` 子 shell 的 cd 不影响父 shell，后面 `grep src/ui.js` 会因路径不对而静默 0 命中（我第一版就是这么"验证"的）。要么写 `worker/src/ui.js`，要么在同一子 shell 里做完。
- 变异测试（注入 bug 看测试是否变红）是判断"新测试是不是装饰"的唯一可靠手段；本轮据此确认 `review.test.mjs` 恰好只红对应项。
- **有 pyyaml 可用**（此前误判"本机无 python"）：`C:/Users/leilaomi/.workbuddy/binaries/python/versions/3.13.12/python.exe`（`D:/WorkBuddy/Data/.workbuddy/binaries/python/` 同名镜像）。改完 workflow 直接 `yaml.safe_load` 一遍，比肉眼数缩进可靠。
- **沙箱里删文件必须给绝对路径**：`rm _mut2.mjs` / `rm scripts/x/_verify_tmp.mjs` 会报「删除目标不明确：无法基于当前工作目录解析路径」，`cd` 过去也没用。写全 `rm -f D:/.../文件` 才放行。
- **重跑统计报告要注意 MC 次数**：`RANDOMNESS_SIMS=300` 之类的调试跑会**就地覆盖** `docs/randomness-*.md`，把已归档结论的 p 值改掉。验完必须用默认 1200 重跑复原，并核对关键读数（`chi2R=44.5438` / `p=0.0250 (15/1200)`）逐位回到原值。
