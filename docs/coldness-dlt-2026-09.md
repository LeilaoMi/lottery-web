# 大乐透「冷门度」拟合：一个负结果的完整留档（2026-09）

**结论先行：目标上样本外复现了（组合指数最热/最冷五分位 = 1.30×，Mann-Whitney p=0.007），但预注册的「固定奖金档安慰剂」对所有候选特征全部失败，因此 `keep = []`、`coefficients = {}` —— 按双色球那套验收标准，大乐透这一版没有任何系数可以发布。** 这是一个负结果，不是成功结果。

## 3. 拟合（2015+，严格时序 70/30）

训练 2015-01-03→2023-03-18 (n=1227)，检验 2023-03-20→2026-09-09 (n=526)。目标 `log1p(一等奖注数 / (销量/亿元))`。后区冷热号只用训练段排序（HOT=5,10,7 / COLD=11,12,2）。

| 特征 | 样本内 | 样本外 | 同号 | 样本外四等奖(固定档) | 一等奖特异偏效应* |
|---|---|---|---|---|---|
| allLe31 | 1.099 | 1.102 [1.021,1.189] | ✓ | 1.148 ✗ | 0.987 [0.922,1.058] |
| nLe12hi | 0.997 | 1.174 | ✗ 反号 | 1.168 | 1.048 |
| sumHi | 0.972 | 0.913 [0.847,0.985] | ✓ | 0.876 ✗ | 1.011 |
| backCold | 0.904 | 0.925 [0.859,0.997] | ✓ | 0.916 ✗ | 0.976 |
| backHot | 1.067 | 1.025 | ✓ | 1.059 | 0.989 |
| hasTail8 / hasTail4 / consec | 1.020/0.963/1.022 | 1.024/0.957/1.022 | ✓ | ≈1 | 均不显著 |

\* OLS：`log 一等奖率 ~ 特征 + log四等奖率 + log五等奖率 + 截距`（样本外），把「本期整体中奖密度」吸收掉后剩下的才是一等奖特有的超买信号。

- 组合指数（只用训练段系数）样本外：Pearson r=0.122，Spearman ρ=0.158，最热/最冷五分位均值比 **1.299**（样本内 1.617，收缩 19.6%），MW p=0.007。
- **噪声安慰剂（开球顺序，与号码集合无关，必须 =1.00）**：backOrder 1.005、ordAsc 1.058、ordMaxFirst 1.044，三者 95%CI 均覆盖 1 → 估计量本身无时代漂移偏差，测出来的效应不是流水线 bug。
- 时代对比：allLe31 在 2015 前是 0.894/0.921（与 2015+ 反号）→ 按污染处理，不作行为证据。跨时代同号 6/11。

## 5. 为什么安慰剂在大乐透几乎不可能通过（方法论发现）

双色球的安慰剂干净，是因为**二等奖只依赖红球**，蓝球冷热在它上面必须是 1.00。大乐透**没有任何一档奖金只依赖后区**：三等奖=前区5中+后区0中，四/五等奖=4中/3中的邻域，全都含前区。一个前区组合被超买时，它的邻域（4中5）同样被超买，低奖级注数被同一机制推高，且样本更大（1.15–1.24 反而高于一等奖的 1.10）。所以「固定档有效应」在大乐透既可能是混淆、也可能是真实的邻域人气，**本数据集无法区分**。再叠加一等奖特异性 OLS 把 allLe31 从 1.102 打到 0.987（这是过度控制——固定档是中介变量而非混杂），只能说：**现有证据不足以把它当作可发布的冷门度系数。**

## 6. 诚实边界

- 本特征**不改变中奖概率**，任何组合中一等奖概率相同；只改变中奖后与人分享的比例。
- 期望回报仍为负（大乐透返奖率约 50%），避开热门不能把游戏变成正期望。
- 若要真正验证，需要集合外的**人气代理**（各组合实际投注分布 / 500.com 或体彩的注数分布），而不是用固定奖级当安慰剂。
- `scripts/coldness/out/dlt.json` 里 `keep=[]`、`coefficients={}`；`stats.perFeature` 与 `stats.tier1Specific`、`uniformity`、`eraComparison` 全部保留供复核，`verdict` 给出机器可读判定。

复现：`node scripts/coldness/dlt-fit.mjs [数据文件]`（零依赖，仅用 Node；默认读 scripts/randomness/data/dlt_asc.txt，由 fetch-multi 生成）。机器可读产物 `scripts/coldness/out/dlt.json`。
